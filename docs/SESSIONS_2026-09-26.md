## 🛡️ 2. Análise de Resiliência: O Sistema está Resistente a DHCP?

| Componente | Modo de Rede Atual | Mecanismo de Resiliência a Mudança de IP |
| :--- | :--- | :--- |
| **NVR Xiongmai (`192.168.1.20`)** | IP Estático / Reserva DHCP | Mapeado por MAC `00:12:43:24:4e:c6`. Se mudar, `dynamic_resolver.py` atualiza streams dos canais 02 a 06 e alerta via ntfy. |
| **Câmera Varanda (`192.168.1.16`)** | IP Estático (`DHCP=false` no firmware) | Mapeada por MAC `d4:a3:eb:89:bd:f4`. Se o roteador forçar novo IP, o resolvedor localiza via ARP. |
| **Câmeras 04, 05, 06, 10, 31** | DHCP com lease dinâmico | Resolução a cada 5 minutos pelo `dynamic_resolver.py` via tabela ARP do kernel. |
| **Gateway go2rtc (`192.168.1.99`)** | IP Fixo no nó Peixe | Permanece estático na rede local e em Tailscale (`100.88.42.19`). |

**Conclusão:** O sistema possui **alta resiliência**. A identidade de rede de cada dispositivo é atrelada ao Hardware ID (MAC Address). Nenhuma stream do `go2rtc` fica permanentemente inoperante em caso de renovação ou troca de endereço por DHCP.
